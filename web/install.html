Install on Android

  1. Tap Download Vialbook above.
  2. If Android says it cannot install from this source, tap Settings, then turn on Allow from this source. This is Chrome if you opened this page in Chrome, or WhatsApp if you opened it from a WhatsApp message.
  3. Press the back button to return to the download.
  4. Tap the downloaded file Vialbook. If you cannot find it, open Downloads in Chrome's menu.
  5. Tap Update. On a new phone it says Install instead.
  6. Tap Open. Your records are still there.

What is new

  • Each vaccine now shows one stock total, the same on every screen.
  • When you give a dose, the batch marked use first is the one chosen.
  • Batches past their expiry are no longer counted as stock you can use.
  • Changing a vaccine's price no longer changes the value of doses already given.
  • The last row of vaccines on Give dose is the same size as the rest.
  • Amounts in All entries now say doses.
